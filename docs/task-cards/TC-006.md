TASK CARD TC-006 | Phase 0 | Branch: p0/resources
Goal: Fetch and verify the reference resources defined by ADR-006 and ADR-007 in a reproducible, idempotent way, with consistent chromosome naming, and check that the curated gene sets map to the annotation.
Read first: AGENTS.md; docs/PRD.md sections 6 (compute and size policy), 7, 14; docs/adr/006, 007, 014; config/config.yaml (reference.files, annotation, motifs); config/gene_sets/README.md; docs/machine_audit.md; docs/bioagex_interface.md if TC-003 is accepted (reuse its provenance format).
Needs: TC-001 and TC-002 accepted, and CL-004 copied into the repo.

Resources to fetch (find each official page yourself and quote its URL; do not guess URLs):
1. Genome: GRCm38 primary assembly FASTA that matches GENCODE vM25, UCSC-style names (chr1 ... chrM).
2. Annotation: GENCODE vM25 comprehensive GTF.
3. ENCODE mm10 blacklist v2.
4. ENCODE mm10 candidate cis-regulatory elements (cCREs) from the SCREEN registry, with their class labels.
5. JASPAR CORE vertebrates non-redundant motif set in MEME format (record the release number).
Derived: chrom.sizes, samtools faidx index, a Bowtie2 index (build it), TSS and promoter BEDs (promoter = TSS -1000 / +500 as in config), a gene table (gene_id, gene_name, gene_type), and resources/annotation/geneset_mapping.tsv.

Outputs:
1. config/resources.yaml: for each file the name, official page URL, file URL, release or version, retrieval date, SHA-256 (recorded on first download, verified afterwards), licence or usage note, and local path. Keep the paths in config/config.yaml reference.files; if you must rename one, report it.
2. workflow/scripts/py/fetch_resources.py and a rule fetch_resources in workflow/rules/fetch.smk: idempotent downloads, checksum verification, and one provenance record per file in resources/provenance.jsonl (BioAge-X's format if TC-003 is accepted; otherwise {path, source_url, retrieved_utc, sha256, bytes, tool}).
3. docs/resources_report.md: sizes, naming checks, mapping results, unmapped symbols, and the projected sizes of indices you did not build.

Checks to implement:
- Chromosome naming is UCSC style in the FASTA, GTF, blacklist and cCREs. If a file differs, rename deterministically with a documented mapping; never silently.
- Gene-set mapping: map config/gene_sets/iegs_v1.tsv and plasticity_v1.tsv to GENCODE vM25 by gene name, then by alias. List every unmapped symbol. Report mapped versus unmapped counts per tier.
- The six symbols Fos, Arc, Npas4, Egr1, Junb and Nr4a1 are present in the GTF.

Acceptance tests (paste the outputs in the report):
1. snakemake -n fetch_resources works. A real run completes, and a second run does nothing.
2. samtools faidx succeeds. Every chrom.sizes contig is in the FASTA. chr1-chr19, chrX, chrY and chrM are present. State the total contig count.
3. The GTF is valid gzip or plain text, its header names GENCODE M25 (quote the header line), and the six IEG symbols are found.
4. Every contig in the blacklist and cCRE files appears in chrom.sizes (show the bedtools or awk command).
5. bowtie2-inspect -s on the index lists the same contigs as the FASTA.
6. config/resources.yaml has a SHA-256 for every file, resources/provenance.jsonl has one record per download, no single file is above 20 GB, and the total disk used is reported.
7. docs/resources_report.md shows zero unmapped tier 1 symbols, or lists them all for Claude to review. Tier 2 may have unmapped symbols, which must be listed.

Do not: build STAR, Salmon, Bismark or HOMER genome indices (report their projected sizes and ask); guess URLs or checksums; commit anything under resources/; edit the gene-set files (report problems to Claude); install software outside the project environments.
