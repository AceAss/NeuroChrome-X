Read first: AGENTS.md; docs/PRD.md sections 1, 8 (items 5-6), 9 (bioagex_export), 12 (species risk), 15; docs/adr/002, 006, 013, 014. In the BioAge-X repo, read PROMPT.txt (or any build-prompt document) as design intent, then verify against the code. Intent is not evidence.

Outputs: docs/bioagex_interface.md with exactly these sections. Every factual statement carries a path:line citation or the output of a command you ran. Write UNKNOWN where you could not establish something; never guess.
