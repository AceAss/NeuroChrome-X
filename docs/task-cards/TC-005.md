Read first: AGENTS.md; docs/PRD.md sections 6 (A1, B1), 9; docs/adr/004, 006, 012; src/neurochromx/io/samplesheet.py (the schema you must satisfy).
Needs: TC-001 and TC-002 accepted, CL-003 copied into the repo.

- A1, activity, ATAC + RNA, adult dentate gyrus: GSE82010, GSE86365 (ATAC); GSE82011 (overexpression ATAC); GSE82012 (knock-down ATAC); GSE82013, GSE86366 (RNA).
- B1, aging, ATAC + RNA, whole hippocampus, young (10 weeks) vs aged (80 weeks), both sexes: GSE244503, GSE244504, GSE244505, GSE244506; ENA project PRJNA1023281 and related.

Outputs:
1. config/dataset_registry.tsv: one row per (study, assay): A1 ATAC, A1 RNA, B1 ATAC, B1 RNA. Use the header TC-001 created; if it differs from PRD section 6, report the difference. 2. config/draft_samples/su2017.tsv and config/draft_samples/achiro2024.tsv: one row per sample in the schema of src/neurochromx/io/samplesheet.py (study_id su2017 and achiro2024; entry_point fastq; gsm and srr filled; path_or_uri empty). Prefer the characteristics fields over titles; report conflicts. At most 3 requests per second. Cache raw responses under data/metadata_cache/ (git-ignored). Any helper script goes in workflow/scripts/py/registry_fetch.py (standard library plus what the py_core environment has).
